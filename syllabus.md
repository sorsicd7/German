# Syllabus: German (self-study, A2 → B1)

*Version 1 · 2026-10-11. Not a university course: no credits, no exam date yet. Goal: **real grammar control at A2,
then B1**, so you can pass a B1 exam (telc or Goethe) in spring/summer 2027 and use German at work and in daily life.*

## 1. Facts
| Item | Value |
|---|---|
| Start level | A2 (self-assessed), grammar weak ("I don't know the grammar") |
| Target | **B1 exam (telc Deutsch B1 or Goethe-Zertifikat B1), May–July 2027** (book it in February) |
| Time | ~4.5 h/week: 2 × 90-min grammar blocks (Wed 16:45, Fri 11:00) + 15 min vocabulary every day + 10 min in the Saturday quiz |
| Pause | exam weeks W15–W16 (vocabulary only); light in H1/H2 |
| Book (pick one and stay with it) | **Grammatik aktiv A1–B1** (Cornelsen) or any A2–B1 grammar book with an answer key |
| Free extras | Deutsche Welle "Nicos Weg" (free A1–B1 video course: listening + grammar); a vocabulary app (Anki) |
| Also check | the TU Dortmund language centre: a German (DaF) A2/B1 course that fits Friday morning, and language tandems |

## 2. Grammar map (A2 consolidation → B1)

| ID | Topic | Level | Week |
|---|---|---|---|
| G00 | Level check (placement) | – | W1 |
| G01 | Sentence structure: verb in position 2, questions, the sentence bracket (Satzklammer) | A1–A2 | W1 |
| G02 | Present tense: regular, irregular, separable and inseparable verbs | A1–A2 | W2 |
| G03 | Articles, gender, plural; **Nominativ and Akkusativ** | A1–A2 | W3 |
| G04 | **Dativ**: articles, pronouns, verbs with dative | A2 | W4 |
| G05 | Prepositions: with Akkusativ, with Dativ, two-way prepositions (Wechselpräpositionen) | A2 | W5 |
| G06 | **Perfekt** (haben/sein, Partizip II) | A2 | W6 |
| G07 | Präteritum (sein, haben, modal verbs, common verbs); modal verbs; imperative | A2 | W7 |
| G08 | **Adjective endings** I (after der/die/das) | A2 | W8 |
| G09 | Adjective endings II (after ein/kein, no article); comparative and superlative | A2–B1 | W9 |
| G10 | A2 review test + repair | – | W10 |
| G11 | **Subordinate clauses**: weil, dass, wenn, ob, als/wenn (verb at the end) | A2–B1 | W11 |
| G12 | Relative clauses (Nom., Akk., Dat.) | B1 | W12 |
| G13 | Reflexive verbs; verbs with prepositions (warten auf …); da-/wo-words | B1 | W13 |
| G14 | Infinitive with zu; um … zu / damit | B1 | W14 |
| G15 | **Konjunktiv II** (würde, hätte, wäre, könnte): polite requests, wishes, "if" | B1 | W17 |
| G16 | Passive (present, past, with modal verbs) | B1 | W18 |
| G17 | Time connectors: bevor, nachdem, während, seit, bis; Plusquamperfekt | B1 | W19 |
| G18 | Genitiv; wegen, trotz, während | B1 | W20 |
| G19 | Two-part connectors: nicht nur … sondern auch, entweder … oder, je … desto | B1 | W21 |
| G20 | B1 exam format: writing an email, speaking tasks, listening, reading | B1 | from W22 |

Skills beside grammar (every week): 15 min vocabulary daily · one DW "Nicos Weg" episode in the Friday block ·
one short text written with the week's grammar (corrected by Claude).
